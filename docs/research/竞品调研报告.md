# AI 知识答题系统 · 竞品调研报告

- 日期：2026-09-22
- 调研方式：GitHub API 检索 + 竞品官网直连验证（title/description）+ 百度搜索结果 + Bing 搜索
- 说明：搜索引擎结果受反爬影响有噪声，本报告中产品定位与功能均以**官网/仓库原文**为准

---

## 1. 结论速览

1. **"AI 知识的答题产品"确实存在，但几乎全部挤在"求职面试题库"这一个场景里**（面试鸭、吴师兄、小林coding、牛客）。
2. **"AI 出题工具"是另一个成熟赛道，但都是教师/培训向**（给老师生成题发给学生），不是自学者向（每天给自己出 10 题）。
3. **通用答题平台（考试宝、问卷星、题答答）已经具备 AI 出题、AI 导题、错题本能力**，产品功能不是壁垒，**内容质量才是**。
4. **最大的免费替代品威胁是 Gemini Notebook（原 NotebookLM）和 ChatGPT 的学习模式**——它们能从你自己的资料生成测验和闪卡，但缺少结构化分类体系和跨会话的长期掌握度画像。
5. **明确的市场空白**：目前没有一个产品在做"**面向在职 AI 工程师、每天 10 题、每题可溯源到论文/官方文档、按知识域给出掌握度画像**"的持续性知识巩固。

## 3. 逐类分析

### 3.1 A 类 · 直接同质竞品（AI/大模型题库）

| 产品 | 定位 | 关键能力 | 对我们的启示 |
| --- | --- | --- | --- |
| **面试鸭**（mianshiya.com） | 程序员面试刷题平台，10000+ 题 | 有专门的"**AI 大模型面试题库**"，覆盖大模型原理、RAG、Agent、Prompt 工程、LangChain、向量数据库、微调部署；每道题附深度解析与图解；Web + 微信小程序 + IDE 插件多端同步 | **最强直接竞品**。但明确面向"求职"，题目是面试问答式，不是每日巩固；且题目是"八股"而非"工程实践" |
| **吴师兄大模型**（cxyxiaowu.com） | 大模型面试题库 + 训练营 | 851 道题按真实面试链路重排，含项目面试题；主站是算法题（LeetCodeAnimation 76k star）+ AI 答疑 | 面试题"按链路组织"这个思路可借鉴到分类体系 |
| **小林coding**（xiaolincoding.com） | 图解八股文 | 有"图解 Agent + RAG + LLM 大模型面试题"专题 | 图解 + 体系化是差异化手段 |
| **牛客网**（nowcoder.com） | 校招/社招笔试面试平台 | 企业真题模拟考试、AI 面试评估 | 企业真题是稀缺内容源 |
| **AgentGuide**（GitHub 9.9k star） | AI Agent 开发指南 | LangGraph 实战、高级 RAG、大模型面试题库、强化学习、数据合成 | **开源免费替代品**，但它是资料库不是答题产品，无答题/统计/推荐 |

**结论**：这一赛道内容上已经很卷，但**产品形态都是"题库浏览 / 面试突击"**，没有"每日任务 + 长期掌握度"的形态。

### 3.2 B 类 · 通用答题与考试平台

| 产品 | 定位 | 与 AI 相关的能力 |
| --- | --- | --- |
| **考试宝**（kaoshibao.com） | "可以导入题库的在线考试刷题学习平台" | **AI 出题**（定制化出题、减少重复）、**AI 一键导题**（纸质题 10 分钟变在线题库）、错题本、组卷 | 
| **问卷星**（wjx.cn） | 问卷调查 + 在线考试 | AI 出题、模板库、统计分析 |
| **题答答** | AI 驱动的智能考试管理平台 | AI 出题 / AI 阅卷 / AI 分析报告 |
| **考试云** | 在线培训考试平台 | AI 考试智能体、AI 命题、监考 |
| **超星学习通 / 雨课堂** | 高校教学平台 | 课堂测验、题库组卷 |
| **粉笔**（fenbi.com） | 公考/职业考试培训 | 规模化题库 + 智能推题 + 模考大赛 |

**结论**：这说明"AI 出题 + 导入 + 错题本 + 组卷"是**已经商品化的能力**，单纯做这些没有壁垒。它们的短板是**内容不聚焦 AI 工程知识**，且题库是用户自己导入的。

### 3.3 C 类 · AI 记忆与学习 App（交互范式参考）

| 产品 | 亮点 |
| --- | --- |
| **Anki** | 间隔重复的事实标准（FSRS 算法），开源，可自定义 |
| **RemNote** | "Study Faster with AI Flashcards, Quizzes & Summaries"，笔记 + AI 闪卡 + 测验 |
| **Brainscape** | 自信度评分驱动的重复算法 |
| **Mochi / Traverse** | 现代 UI 的间隔重复工具 |
| **Quizlet / Knowt / StudyFetch** | Knowt 直接自称"#1 Free Quizlet Alternative with AI Study Tools"；StudyFetch 主打 AI 生成与练习 |
| **扇贝 / 百词斩** | 中文每日打卡范式（"14 年词汇记忆研究"、"AI 驱动个性化备考路径"） |
| **Duolingo** | **每日任务 + streak 的产品范式标杆**（我们的"每日 10 题"本质就是这个模式） |

**结论**：这些产品的**交互与留存机制值得直接抄**（每日任务、streak、错题回流、掌握度），但它们的知识域是语言/通用学科，**没有 AI 工程知识的结构化体系**。

### 3.4 D 类 · AI 出题工具（教师/培训向）

| 产品 | 定位 |
| --- | --- |
| **QuestionWell**（questionwell.org） | "AI-Powered Teaching Tools"，生成标准对齐的教学材料 |
| **Conker**（conker.ai） | "AI powered quizzes"，快速生成测验与形成性评价 |
| **MagicSchool**（magicschool.ai） | 面向学区的 AI 平台 |
| **Diffit**（diffit.me） | 教师差异化教学资源生成 |
| **Yippity**（yippity.io） | "Free AI Quiz & Question Generator"，从文本和 PDF 出题，可导出 Word/PDF |
| **Quizgecko**（quizgecko.com） | AI 出题（本站有反爬，未能直连验证） |
| **Eduaide / Brisk Teaching / SchoolAI / ClassPoint / Formative / Almanack** | 教师工具链 |
| **Kahoot / Quizizz / Blooket / Gimkit** | 游戏化课堂答题 |

**结论**：**出题技术不是壁垒**，市面上有大量成熟工具。它们的共同点是"**老师出题 → 学生答**"，我们的场景是"**自己给自己出题 → 自己答**"，且用户是 AI 从业者而非教师。

### 3.5 E 类 · 免费替代品与知识来源

| 产品 | 威胁点 |
| --- | --- |
| **Gemini Notebook（原 NotebookLM）** | 从你的资料生成**测验和闪卡**，且完全免费、背靠 Google。**这是最大的"顺手免费"替代品** |
| **ChatGPT 学习模式** | 对话式学习与自测 |
| **OpenAI Academy / Anthropic Claude Academy** | 官方免费课程与练习 |
| **Hugging Face Learn / Google Skills / AWS Skill Builder / Microsoft Learn / DeepLearning.AI / Databricks** | 官方课程自带随堂测验 |
| **阿里云大模型 ACA/ACP 认证** | **已验证的付费需求**：市面上有大量第三方 ACP 题库（"阿里云 ACP 练习题参考（817 道，带答案）") |
| **SuperCLUE / OpenCompass** | 大模型评测榜单。不是给人答题的，但可作为**难度校准与知识点参考** |
| **极客时间 / Datawhale / 飞桨 AI Studio / 阿里云天池** | 中文 AI 学习生态 |

**结论**：Gemini Notebook 解决了"从资料生成题"，但**没解决**：结构化分类体系、跨会话的长期掌握度画像、题目质量把关（溯源 + 干扰项错因）、每日任务感。

## 4. 空白与机会

**已被占满的位置**

- 求职面试题库（面试鸭、吴师兄、小林coding、牛客）
- 通用 AI 出题工具（考试宝、QuestionWell、Yippity 等）
- 从个人资料生成测验（Gemini Notebook、ChatGPT）
- 间隔重复记忆工具（Anki、RemNote）

**没有被占的位置（我们的机会）**

| 机会点 | 说明 |
| --- | --- |
| **定位空白** | 现有中文产品都是"求职/考证"导向，**没有"在职工程师的日常知识巩固"定位** |
| **内容空白** | 通用平台的 AI 出题能力很强，但**没有权威、可溯源的 AI 工程知识题库**（面试鸭是八股问答，不是工程判断） |
| **形态空白** | 没有产品做"每天 10 题 + 长期掌握度画像"（Duolingo 范式 × AI 工程知识） |
| **解析空白** | 没有产品做**分层解析（为什么对 + 干扰项为什么错）+ 每题溯源到论文/官方文档** |
| **付费验证** | 阿里云 ACP 大模型认证题库有大量第三方付费内容，说明"AI 知识考核"有人愿意付钱 |

## 5. 对 MVP 的修正建议

基于竞品调研，建议对原 MVP 文档做 4 处调整：

1. **差异化表述要改**：原文档说"分层解析是差异化"，但竞品（面试鸭）也强调"深度解析"。真正的差异化应该是 **"可溯源到一手资料 + 干扰项错因 + 工程实践判断题"**，而不是泛泛的"解析详细"。
2. **明确不与面试鸭正面竞争**：不做"面试八股题库"，改做"**工程实践知识 + 知识域掌握度**"。题目示例："线上 RAG 召回率正常但答案不对，你会先查哪一层？"
3. **冷启动可以借力**：阿里云 ACP 大模型认证的考点大纲、面试鸭的 AI 大模型题库分类，都可以作为**分类体系的参考基准**（不抄题，抄知识点覆盖面）。
4. **必须强化"每日任务 + streak"**：这是对抗 Gemini Notebook 这类"随手可用"工具的唯一护城河——它们没有任务感和长期记录。

**建议的分类体系（对标竞品覆盖度）**

```
大模型基础（Transformer/注意力/位置编码/推理采样）
提示工程（CoT/Few-shot/结构化输出）
RAG（切分/向量检索/重排序/混合检索/评估）
Agent（规划/工具调用/多智能体/MCP/记忆）
本体与知识图谱（RDF/OWL/SPARQL/图谱增强 RAG）
微调与对齐（SFT/LoRA/RLHF/DPO）
评估与可观测（评测集/LLM-as-Judge/Tracing）
工程与部署（推理服务/成本/缓存/并发）
多模态（VLM/文生图/语音）
```

## 6. 风险提示

| 风险 | 说明 | 应对 |
| --- | --- | --- |
| Gemini Notebook 免费替代 | 能从资料生成测验，且是 Google 产品 | 靠"题库质量 + 分类体系 + 长期画像"错位竞争 |
| 面试鸭向下兼容 | 已有 10000+ 题、多端、品牌，随时可加"每日推荐" | 抢先占位"日常巩固"心智，内容做工程实践向 |
| 通用平台内容补齐 | 考试宝有 AI 导题能力，用户可自己导入 AI 资料 | 提供开箱即用的高质量题库，降低用户成本 |
| 出题技术无壁垒 | AI 出题已商品化 | 壁垒放在**审核流程 + 溯源 + 数据回流淘汰坏题** |
| 版权 | 面试题/课程内容有版权 | 只用官方文档与论文，社区内容只做灵感 |
